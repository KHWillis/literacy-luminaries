# Website Update for The Literacy Luminaries — Sept 2026

A plain-language update on where things stand with the website, written to share
directly with the three founders. No jargon — see the `docs/` folder for the
technical detail behind any of this if it's ever useful.

---

## Where things stand

We've spent time mapping out how the site should be built so that it looks
professional and sophisticated from day one, and — just as important — so that
**you three can update it yourselves** once it's live, without needing to wait on
me for every small change.

That second part is a big deal: the plan we've landed on means you'll be able to log
into a simple, form-based editor and update things like:
- Founder bios and photos
- Service page descriptions (Academic Therapy, Resources, Professional Learning)
- New resources/offerings as you add them over time

...all without touching any code, and without needing me involved for routine
content updates.

## The plan in a nutshell
- The site will be fast, secure, and cheap to run (roughly the cost of the domain
  name per year — well under $20/yr in hosting-type costs).
- It'll be built with room to grow — the "coming soon" sections (Resources,
  Professional Learning) can quietly turn into real, full sections later without a
  rebuild.
- I'll be building it using some newer, well-regarded tools that also happen to be
  fun for me to build with — which means I can move faster and add some genuinely
  nice touches (subtle motion/animation, for instance) without it costing you
  anything extra or adding ongoing maintenance work for me.

## A little bit of homework — no pressure, just curiosity
I'd love your eyes on a few real websites built with the same toolkit I'm planning
to use, just to gather reactions. You don't need to know anything technical — just
click around each one for a couple of minutes and jot down anything you react to,
good or bad. Things like:

- "I like how the header looked on scroll"
- "This felt too busy / too quiet"
- "I like how their About page introduced the team"
- "This color palette felt right / felt off"
- "I liked how their homepage explained what they do quickly"

   overdone."

(If any of these don't load for you, no big deal — just skip it and let me know,
some of these smaller sites come and go.)

### What I'll do with your feedback
Nothing needs to be decided yet — I just want a sense of your taste before I start

## Optional: creating a free GitHub account
This part is genuinely optional, and not something you'll need day-to-day — but a
couple of you asked, so here's the short version.

Everything technical about the site (including documents like this one) lives on a
platform called **GitHub**. Right now it's set up so anyone with the link can view it
— no account needed. At some point soon we'll lock it down to private (once there's
more sensitive info in there), and at that point you'd need a free account to keep
viewing things there.

You will **not** need to do anything technical with it — no code, no editing, nothing
to maintain. Worst case, it's just a login so you can occasionally view a document or
a plan. If it's ever more convenient, you can just ask me to email/text you a copy
instead of looking at GitHub directly — either way is fine.

If you'd like to set one up anyway (2 minutes, totally optional):
1. Go to **https://github.com/signup**
2. Enter an email, create a password, and pick a username (anything you like)
3. Verify your email when it asks
4. Once logged in, plug this link into your browser to see this page again with your
   account: **https://github.com/KHWillis/literacy-luminaries**

That's it — no further setup needed. If you get stuck on any step, just send me a
screenshot and I'll help.
